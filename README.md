# Msambizi Landing Page

Nuxt 3 (SSG) marketing landing page for Msambizi, repositioned for universities and colleges.

## Develop

```bash
npm install --ignore-scripts
node node_modules/esbuild/install.js
npm run dev
```

## Build (static)

```bash
npm run generate
```

Output: `.output/public` — deploy to any static host or to the domain root.

## Notes

- No product screenshots or internal UI are shown; all visuals are abstract.
- Primary audience: universities & colleges. Tutors and students are secondary.
- Sign-in links point to `https://app.msambizi.school/login`.
- Contact/demo email: `support@msambizi.school`.
